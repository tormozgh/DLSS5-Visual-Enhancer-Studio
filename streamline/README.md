# NVIDIA Streamline 2.13 Plugins

This directory houses the NVIDIA Streamline 2.13 runtime plugins for Real-Time Rendering:
- `sl.interposer.dll`
- `sl.dlss_nr.dll`
- `sl.dlss_g.dll`
- `sl.dlss.dll`
- `sl.nis.dll`
- `sl.reflex.dll`
- `nvngx_dlssnr.dll`
- `nvngx_dlssg.dll`

These binaries are distributed with the official pre-packaged releases in the GitHub Releases section.
